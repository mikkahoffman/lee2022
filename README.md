# Replication Project - mikka_lee2022

This repo is a project aiming to replicate Lee and Gelman (2022) for Psych 201 at UCSD. Here you can find the original paper, replication report, data, and experiment code. 

# File Overview:
* original_paper: contains pdf file of the original paper by Lee and Gelman (2022)
* writeup: contains .qmd and .pdf versions of the final replication report. Analysis scripts are contained within these files. 
* data: contains preprocessed data 
* index.html: code for the JsPsych experiment. The html experiment can be accessed at <https://mikkahoffman.github.io/lee2022/>
